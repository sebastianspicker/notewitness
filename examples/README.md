# Examples

`synthetic-lesson/` is a small evidence-graph project for trying the validation,
inspection, lesson-note, and static-demo paths without private media. It contains
no recording, real participant, participant identifier, or model output.

The example is part of the NoteWitness source distribution under the repository
license. Its synthetic rights record describes the sample source inside the
project; it is not a benchmark license or a claim about model performance.
