# Examples

`synthetic-lesson/` is a small evidence-graph project for trying the validation,
inspection, lesson-note, and mock-data demo paths without private media. It
contains no recording, no real participant, no participant identifier, and no
model output.

The example ships with the NoteWitness source distribution under the repository
license. Its synthetic rights record describes the sample source inside the
project; it is not a benchmark license or a claim about model performance.
