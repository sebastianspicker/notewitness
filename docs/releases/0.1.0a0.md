# NoteWitness 0.1.0a0

Proposed release title: NoteWitness 0.1.0a0 public alpha

Status: unpublished working-tree candidate. No commit, tag, package, or GitHub release exists.

## Release summary

This alpha contains a dependency-free Python evidence workbench for private music-teaching research
projects. It includes evidence validation, local media ingest, explicit external ASR and analysis
adapter boundaries, durable local jobs, append-only review, rights-gated exports, and a
session-authenticated loopback browser workbench.

## Included capabilities

- Owner-private offline project storage and evidence-graph validation.
- Local Whisper and JSON analysis contracts with raw and normalized artifact separation.
- Activity, anonymous speaker, note, pitch, instrument, and optional score-alignment hypotheses.
- Durable cancellation, checkpoint, replay, retry, and publication recovery paths.
- Human acceptance and revision records that do not overwrite model output.
- Private transcript and music exports with explicit rights and projection-loss acknowledgement.
- Optional, separately authorized OpenAI text relation suggestions.

## Known limitations

- Models, model weights, Whisper, FFmpeg/ffprobe, analysis engines, media, scores, browsers, and
  devices are not bundled.
- Automatic external-tool processing is advertised only on macOS. Its sandbox denies network
  operations but does not restrict filesystem access by approved executables.
- The workbench is single-user and loopback-only. Session authentication does not protect against a
  malicious process with the same user's filesystem authority.
- No model accuracy, fairness, speaker-error, note-error, pedagogical-effectiveness, or corpus
  suitability claim has been established.
- External runtime, model, browser, and codec compatibility is not guaranteed.
- Speaker labels remain anonymous and run-local. Persistent identity, grading, diagnosis, and
  performance assessment are excluded.
- APIs, schemas, and project data formats may change during the alpha series.

## Installation and migration

Python 3.11 or newer is declared. Installation uses `python -m pip install .`; the exact candidate
must still pass the isolated wheel build and install procedure before publication.

There is no prior public release and therefore no supported upgrade or data migration path.
